# Quiz mode (work in progress)

The full Quiz page is parked here while it is being finished, so it is not
served on the live site. `public/index.html` shows a "Coming soon" screen
instead.

To bring it back: move `index.html` and `app.js` into `public/` (replacing the
Coming soon page) and remove the `/` redirect to `agile.html` in `server.js`
if Quiz should be the start page again.
